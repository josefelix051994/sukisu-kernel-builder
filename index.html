🛠 SukiSU-Ultra 内核编译

选择设备型号与内核版本, 一键触发 GitHub Actions 编译, 实时查看进度, 完成后下载内核

1 · GitHub Token

需要具有 repo + workflow 权限的 GitHub Token 才能触发编译与下载产物。 Token 只保存在你浏览器的 localStorage 中, 不会上传到任何服务器。

2 · 选择设备与版本

高级选项

产物命名: <品牌>_<机型>_<机型代码>_<内核版本>_SukiSU-<版本>_<日期时间>.zip,例如 Redmi_K40+POCO_F3_alioth_4.19.113_SukiSU-v3.0.0_20261120-2003.zip;勾选「自动发布」后成功编译会自动创建带备注说明的 GitHub Release。
