# builds/ — 自动生成的独立编译脚本

由 `bash tools/gen_build_scripts.sh` 根据 devices.conf 生成, **不要手改**。
每个文件对应一个设备机型 + 内核版本组合, 直接执行即可编译;
也可以运行根目录的 `bash build-all.sh` 一次性跑完全部组合。
